# Security Policy

This repository follows the SZL Holdings organization security policy, which sets the disclosure
process, response times, supported versions and scope:
https://github.com/szl-holdings/.github/blob/main/SECURITY.md

## Reporting a vulnerability

E-mail **security@szlholdings.com**, the contact named in that policy. Please do not report a
suspected vulnerability in a public issue, pull request or discussion: the policy asks for a
reasonable opportunity to investigate and patch before public disclosure.

Please include:

- A clear description of the issue and its potential impact.
- Steps to reproduce, including any proof-of-concept code, requests, or payloads.
- The affected version, commit SHA, or environment.
- Your name and contact details for follow-up and credit (optional).

If this repository is public and has GitHub private vulnerability reporting enabled, you can also
report through its **Security** tab (**Report a vulnerability**).
